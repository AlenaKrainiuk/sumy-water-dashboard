# sumy-water-dashboard
Звіт за результатами аналізів води територій, що постраждали внаслідок бойових дій.  Підготовлено в рамках проєкту «Громадська оцінка ризиків для земель і вод з метою безпечного відновлення громад Слобожанщини»,ГО «НОВА ЕНЕРГІЯ» у межах Проєкту «Імпульс», Міжнародний фонд «Відродження» та Фонд Східна Європа за фін. Норвегії (Norad) та Швеції (Sida)
